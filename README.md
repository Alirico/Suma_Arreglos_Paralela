# Suma_Arreglos_Paralela
comando para compilar: g++ -fopenmp SolucionSumaArreglosParalela_Ali_Rico.cpp -o suma_paralela  
comando para ejecutar: ./suma_paralela  

Este proyecto implementa la suma de dos arreglos de gran tamaño ($N = 1000$) utilizando el estándar OpenMP para programación paralela. El desarrollo se enfocó en la eficiencia algorítmica y la portabilidad en entornos de nube, validando la solución en GitHub Codespaces.  
Lenguaje: C++  

Paralelismo: OpenMP 4.5  

Compilador: g++ (Ubuntu 11.4.0)  

Entorno de Desarrollo: GitHub Codespaces (Cloud-Native)  

Se seleccionó GitHub Codespaces y el compilador g++ sobre entornos locales (Windows/MSVC) debido al soporte superior de g++ para estándares modernos de OpenMP, garantizando una gestión de hilos más eficiente y alineada con entornos de producción de HPC (High Performance Computing).
